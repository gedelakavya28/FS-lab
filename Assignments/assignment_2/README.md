# MongoDB Student Management System

## Objective

Develop a simple MongoDB-based student management system to store,
retrieve, update, and manage student information.

## Database

Database Name: collegeDB

Collection Name: students

## Student Fields

- rollNo
- name
- branch
- year
- marks
- email

## Operations Performed

1. Insert student records
2. Display all students
3. Display students by branch
4. Find students scoring more than 75
5. Search student using rollNo
6. Search students using conditions
7. Update student marks
8. Update student email
9. Delete student using rollNo
10. Sort students by marks
11. Create index on rollNo
12. Demonstrate index usage

## Real-Time Queries

- Find students scoring above 80
- Find students scoring below 50
- Find the highest-scoring student
- Find students belonging to a particular branch
- Display students sorted according to marks

## Technologies Used

- MongoDB
- MongoDB Shell (mongosh)
- VS Code
